# YAL VPN Bot

ربات فروش تلگرامی برای سرور Outline، همراه با مینی‌اپ (Telegram Mini App).

## امکانات
- خرید اکانت، تمدید و افزایش حجم روی همان لینک، کیف پول و شارژ با رسید و تایید ادمین
- مینی‌اپ فارسی (تم بنفش، حالت تیره و روشن) با داشبورد، مصرف لحظه‌ای، لینک و QR کد
- نقش ادمین اصلی و ادمین فرعی، با مشتری‌های جدا برای هر ادمین
- وارد کردن اکانت‌های قدیمی اوتلاین و اختصاص آن‌ها به ادمین‌ها
- گزارش روزانه‌ی فروش، گزارش مصرف شبانه برای مشتری، بکاپ هفتگی دیتابیس، ارسال همگانی

## پیش‌نیاز
- سرور Ubuntu یا Debian (ترجیحا همان سروری که Outline روی آن نصب است) با دسترسی root
- یک ربات از [@BotFather](https://t.me/BotFather) و توکنش
- (اختیاری) یک دامنه برای مینی‌اپ، مثل `app.example.com`، با رکورد A به IP سرور

## نصب
```bash
git clone https://github.com/USERNAME/outlinevpnbot.git
cd outlinevpnbot
sudo bash install.sh
```
اسکریپت این‌ها را می‌پرسد: توکن ربات، آیدی عددی ادمین اصلی، آدرس مدیریت Outline (اگر روی همین سرور باشد خودش پیدا می‌کند)،
دامنه‌های ورودی مشتری، شماره کارت، یوزرنیم پشتیبانی، قیمت و حجم پلن‌ها، ضریب حجم و دامنه‌ی مینی‌اپ.
بعد اتصال به Outline و تلگرام را امتحان می‌کند، ربات را به‌صورت سرویس systemd نصب می‌کند و برای مینی‌اپ HTTPS (Caddy) می‌گیرد.

اسکریپت به Outline، تانل‌ها و کلیدهای موجود دست نمی‌زند.

## به‌روزرسانی
```bash
cd outlinevpnbot && git pull && sudo bash install.sh update
```

## دستورهای مفید
```bash
sudo bash install.sh status          # وضعیت سرویس
journalctl -u vpnbot -f              # لاگ زنده
nano /opt/vpnbot/.env                # تغییر تنظیمات (بعدش: systemctl restart vpnbot)
```
فایل تنظیمات و دیتابیس توی `/opt/vpnbot` هستند و بکاپ روزانه توی `/root/vpnbot-backups` ذخیره می‌شود.

## امنیت
- **فایل `.env` و `bot.db` را هرگز توی گیت‌هاب نگذار.** `.gitignore` پروژه جلویشان را می‌گیرد.
- ریپو را **Private** نگه دار.
- اگر توکن ربات یا آدرس مدیریت Outline جایی لو رفت، توکن را با `/revoke` در BotFather عوض کن.
- `bot.db` شامل لینک اکانت‌هاست؛ بکاپ‌ها را محرمانه نگه دار.
